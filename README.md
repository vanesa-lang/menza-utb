# Menza UTB a laktóza

Web: https://vanesa-lang.github.io/menza-utb/

Týdenní jídelníček menzy UTB, jídla s alergenem 7 (mléko, vč. laktózy) jsou označená červeně. Stránka se obnovuje sama každý všední den ráno a v neděli odpoledne.

Neoficiální stránka, data přebírá z https://jidelnicek.utb.cz.

- `build.py` – stáhne jídelníček a vytvoří stránku
- `template.html` – vzhled (paleta Kolejí a menzy UTB)
- `.github/workflows/update.yml` – automatické spouštění
- kontrolní výpis: https://vanesa-lang.github.io/menza-utb/debug/
